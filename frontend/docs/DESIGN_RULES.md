# Realtor Toolbox Design Rules

The dashboard mockups (desktop + iPhone) are the source of truth. Never redesign screens.

Always match: spacing, padding, icon sizes, shadows, gradients, typography, border radius, colors, animations.

When creating new pages: pretend the UI was designed by Apple, Linear, and Notion together. Maintain consistency — every new page should feel like it belongs beside the Dashboard.

If unsure, copy the Dashboard's existing design language rather than inventing something new.
