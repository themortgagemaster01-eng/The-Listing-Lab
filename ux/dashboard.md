# Dashboard

The dashboard is the Realtor's home base — a single screen replacing the many tools/sites a Realtor would otherwise juggle.

## Layout

**Top**
- Greeting
- Search
- Notifications
- Quick Actions

**Middle**
- Property Cards (one per active listing / Property Workspace)

**Bottom**
- Recent AI Activity
- Marketing Center
- Recent Documents

## Components (MVP)

- Realtor Profile
- Property Dashboard
- AI Marketing Center
- Recent Activity
- Notifications

## Requirements

- Must work perfectly on both desktop and mobile.
- Visual language: lots of whitespace, rounded corners, subtle animations, dark and light mode, minimal clutter — see [BRAND_GUIDELINES.md](../docs/BRAND_GUIDELINES.md).

## Status

This is a description derived from the product spec, not a finished design. See [wireframes.md](wireframes.md) — actual wireframes are still TBD.
