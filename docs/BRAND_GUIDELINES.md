# Brand Guidelines

## Design Inspiration

Tesla, Apple, Linear, Notion. Every interaction should be simple and intuitive.

## UI Guidelines

- Think Tesla, think Apple
- Lots of whitespace
- Rounded corners
- Subtle animations
- Dark and light mode
- No unnecessary clutter

## Primary Colors

- White
- Black
- Graphite
- Accent Blue

See [branding/colors.md](../branding/colors.md) for the color reference sheet.
