# MVP Roadmap

## MVP Features — Dashboard

- Realtor Profile
- Property Dashboard
- AI Marketing Center
- Recent Activity
- Notifications

## Dashboard Layout

**Top:** Greeting, Search, Notifications, Quick Actions
**Middle:** Property Cards
**Bottom:** Recent AI Activity, Marketing Center, Recent Documents

Everything should work perfectly on desktop and mobile.

## Property Workspace

Every listing receives its own workspace. Each workspace stores:

- Listing Photos
- AI Enhanced Photos
- Virtual Staging
- Flyers
- Social Media Posts
- Property Website
- QR Codes
- Payment Snapshot
- Closing Cost Snapshot
- Buyer Packet
- Seller Packet
- Video Scripts
- AI Chat
- Notes
- Documents

Everything generated remains attached to that property forever.
